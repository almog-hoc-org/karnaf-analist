# קרנף אנליסט 🏙️

מערכת מחקר וניתוח שוק הנדל"ן בישראל — מבוססת מאגר עסקאות עצמאי (780K+ עסקאות אמת מרשות המסים, מסווגות יד-שנייה/חדשות לפי שנת בנייה).

## מה במערכת
- **מערכת דאטה**: דפי ערים עם MultiChartStudio (סדרות להשוואה, כל טווח שנים), טבלת ערים עם 4 מדדי מחיר, דירוגים מנורמלים (10+ עסקאות מכל סוג), תובנות אוטומטיות, דשבורד לאומי.
- **ניהול והשוואת עסקאות** (`/deals`): מעקב דירות ללקוח מחפש — הזנת עסקה, השוואה אוטומטית לעסקאות אמת ברחוב/שכונה, סטטוס, משימות, מרפסת/חניות/מחסן.

## הרצה מקומית
```bash
npm install
npx prisma generate
npm run dev
```
דורש את `data/realestate.db` (לא בגיט — 153MB; שמור כ-snapshot ב-Releases) ואת `data/app.db` (נוצר אוטומטית).

## איסוף נתונים
- `scripts/collect-govmap-transactions.ts` — סוויפ רחב (12 שנים, רחוב+מס' בית), ללא דפדפן.
- `scripts/collect-transactions.ts` — ערוץ nadlan עם שנת-בנייה (דורש כרום גלוי :9222); רץ אוטומטית בלילה (launchd `nadlan-nightly`).
- `scripts/aggregate-nadlan-transactions.ts` — בונה את טבלת הסטטיסטיקה שהאתר קורא.
