- **מיקום בניינים**: 173k+ כתובות ב-`address_geocodes` (OSM + govmap).

## מה נשאר, לפי סדר ערך

### 1. מיקום בניינים — הריצה הארצית (מק, כמה ערבים)
```bash
cd ~/karnaf-analist && git pull
KARNAF_GEOCODE_BUDGET_MIN=240 bash scripts/push-geocodes.sh
```
ממשיך מאיפה שנעצר, ניתן לעצירה ב-Ctrl+C. נשארו ~61k כתובות ב-129 ערים
(8.9.2026, אחרי ~24k). כשמסתיים: "אין כתובות לגיאוקוד — הקמפיין הושלם".

**זה החוסם של כל השאר.** עיר בלי מספיק בניינים ממוקמים לא מקבלת מפה
(38 ערים נכשלו בריצת המפות מהסיבה הזאת), והנעצים דלילים.

### 2. אחרי כל ערב של (1) — דוח בשרת
```bash
cd /opt/karnaf && docker compose exec -T app npx tsx scripts/report-neighborhood-coverage.ts </dev/null | grep -A 45 "גיאוקוד"
```
המספרים שחשובים: "ערים עם מפה: X מתוך 165" ועמודת "מ-2022" (36% ב-8.9).

### 3. ריצה חוזרת של nadlan על הערים הגדולות (מק + כרום)
הפיצול לפי סוג עסקה (`deepSlices`) נועד ל-15% משורות 2024–2025 בשכונות
רוויות. עוד לא רץ.
```bash
bash scripts/bootstrap_nadlan_chrome.sh      # ואז באתר nadlan: לפתוח "עסקאות" פעם אחת
KARNAF_NADLAN_INSERT=1 bash scripts/push-nadlan-addresses.sh "ראשון לציון" "רחובות"
```
אם התוספת יפה — להמשיך לתל אביב, ירושלים, חיפה, באר שבע, פתח תקווה, נתניה.

### 4. תחזוקה
- ריבוט לשרת כשמצטברים תהליכי זומבי (`docker compose ps` אחריו).
- `flag-duplicate-deals.ts` רץ בצינור; אין צורך ידני.
