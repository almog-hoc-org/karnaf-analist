רוויות. **עוד לא רץ.**
```bash
bash scripts/bootstrap_nadlan_chrome.sh    # ואז באתר nadlan: לפתוח "עסקאות" פעם אחת
KARNAF_NADLAN_INSERT=1 bash scripts/push-nadlan-addresses.sh "ראשון לציון" "רחובות"
```
אם התוספת יפה — להמשיך לתל אביב, ירושלים, חיפה, באר שבע, פתח תקווה, נתניה.
