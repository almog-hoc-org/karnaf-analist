## שלב 5 — מיקום בניינים דרך govmap, ריצת ניסיון (במק, בלי כרום)

```bash
cd ~/karnaf-analist
git pull
KARNAF_GEOCODE_BUDGET_MIN=30 bash scripts/push-geocodes.sh "בת ים"
```
מדפיס עשר שורות "דגימת תשובה" — להדביק לקלוד. הן מגלות אם govmap מחזיר נקודה
ברמת בניין. אחרי 30 דק׳ עוצר לבד. זה מה שיעלה את "ניתנות למיקום" מ-17%.

## שלב 6 — ריצה חוזרת של nadlan על הערים הגדולות (במק, עם כרום)

1. `bash scripts/bootstrap_nadlan_chrome.sh` — נפתח כרום.
2. בכרום: nadlan.gov.il, לפתוח "עסקאות" של עיר כלשהי פעם אחת.
3. בטרמינל:
   ```bash
   KARNAF_NADLAN_INSERT=1 bash scripts/push-nadlan-addresses.sh "ראשון לציון" "רחובות"
   ```
   הפיצול החדש (לפי סוג עסקה) מגיע לאמצע של שכונות רוויות. אם התוספת יפה:
   ```bash
   KARNAF_NADLAN_INSERT=1 bash scripts/push-nadlan-addresses.sh "תל אביב-יפו" "ירושלים" "חיפה" "באר שבע" "פתח תקווה" "נתניה"
   ```
   אם הסקריפט אומר "הכרום הפסיק לענות": לסגור את הכרום, שלב 1 שוב, ולהריץ שוב.
